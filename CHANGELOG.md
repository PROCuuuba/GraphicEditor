# История изменений

## [1.0.1] — 2026-10-29

- Удалён дополнительный формат GED и реализация Java-сериализации.
- В выборе формата и чтении остались PNG, JSON и SVG.
- Обновлены тесты и документация.

## [1.0.0] — 2026-10-29

### Добавлено

- Единый `Drawing` для растровых элементов, полигонов и фона; прежний
  `DrawingModel` сохранён как совместимый тип для существующих компонентов.
- Режим выбора объектов, визуальное выделение, перемещение и удаление
  растрового элемента или целого полигона.
- История состояний с Undo/Redo: штрих и перетаскивание учитываются целиком,
  новая правка очищает Redo, сохраняются до 100 завершённых действий.
- Общий `EditorSettings` для параметров инструментов, фона и привязки.
- Новый пустой рисунок и единые команды открытия и сохранения.
- Выбор PNG, JSON, SVG и собственного GED с восстановлением исходных
  объектов, оформления и фона. История действий в проекты не записывается.
- `DrawingExporter` с единым обходом и `DrawingBuilder<R>` для пошаговой
  сборки JSON/SVG; `JsonFile` и `SvgFile` — независимые продукты.
- Архитектурные диаграммы и контрольная карта третьего инкремента в `docs/`.

### Изменено

- Версии разделены по учебным этапам: `increment1` — 0.1.0,
  `increment2` — 0.2.0 без файловых операций, `increment3` — итоговая 1.0.0.
- Ранее добавленный PNG перенесён в третий инкремент вместе с остальными
  форматами. Его метаданные `GraphicEditor.Project` остаются редактируемыми.
- Позднее дополнение задания с SVG/JSON и разделением обхода/формата
  реализовано вместе с исходным вариантом Java Serialization в GED.
- README описывает все три версии, работу с форматами, историей и настройками.

Исторические записи ниже отражают прежнюю последовательность разработки.
Наличие PNG в промежуточной 0.2.1 не означает, что файловые операции входят
в текущую учебную ветку `increment2`.

## [0.2.1] — 2026-10-29

### Добавлено

- «Открыть PNG…» и «Сохранить PNG…» в верхней части окна,
  сочетания Ctrl/Cmd + O и Ctrl/Cmd + S.
- PNG проекта: обычное изображение 900×650 и XML с версией формата
  в стандартном блоке `iTXt`, ключ `GraphicEditor.Project`.
- Восстановление элементов кистей, вершин полигонов и их оформления;
  после открытия готовые полигоны можно продолжать редактировать.
- Проверка файла до замены рисунка, подтверждение замены непустого холста
  и сообщение об ошибке для обычного PNG без данных проекта.

### Изменено

- Существующие ветки разделены по версиям: `increment1` содержит первый
  инкремент 0.1.0, `increment2` — второй инкремент 0.2.1.
  Прежняя история и тег 0.2.0 сохранены.
- README объясняет переключение версий и устройство PNG проекта.

На момент промежуточной версии формат проекта был собственным, без совместимости с draw.io и распознавания
фигур из произвольных изображений. Передавать PNG следует исходным файлом:
сторонняя обработка может удалить метаданные. Группы объектов, сохранение
настроек приложения и Undo/Redo в 0.2.1 ещё не были реализованы.

## [0.2.0] — 2026-10-14

### Добавлено

- Векторные полигоны из не менее трёх вершин, создание и отмена черновика.
- Общий интерфейс `Shape` и независимые `FillDecorator`, `BorderDecorator`,
  `ShadowDecorator` для заливки, контура и тени.
- Цвет и толщина контура; цвет, смещение по X/Y и размытие тени.
- Список полигонов, выбор и удаление одной фигуры, несколько векторных фигур
  одновременно с растровым рисунком.
- Встроенные подсказки инструментов.
- Масштаб 25–400%, колесо мыши, жесты прокрутки и pinch-zoom, кнопки масштаба.
- Привязка к вершинам, замыкание нажатием первой вершины и перетаскивание
  вершин завершённого полигона с сохранением оформления.
- Горячие клавиши переключения инструментов, завершения и отмены,
  удаления, масштаба и очистки.
- UML классов, UML последовательности отображения, архитектурная схема
  и контрольная карта требований второго инкремента в `docs/`.
- Модульные и GUI-проверки второго инкремента, сочетаний/порядка декораторов,
  расширяемости и регрессии первого инкремента.
- Приёмочные снимки вогнутого полигона, независимого выключения эффектов,
  пределов толщины контура и отрицательных смещений тени.

### Изменено

- `DrawingModel` хранит растровые элементы и векторные фигуры; очистка
  удаляет оба вида объектов и черновик.
- `DrawingCanvas` отображает растровый слой под полигонами, а оформление
  вычисляется через контекст `ShapeRenderer`.
- Оформление выбранного готового полигона обновляется сразу при изменении
  элементов управления; настройки во время черновика относятся к новой фигуре.
- Холст центрируется и автоматически вписывается при изменении окна;
  ручной масштаб отключает автовписывание до команды «Вписать».
- README актуализирован для версии 0.2.0 и содержит диаграммы текущего кода.

### Исправлено

- Недостаточное использование рабочей области при разворачивании окна.
- Отсутствие привычного масштабирования колесом и жестами.
- Смещение логических координат и размера маркеров при масштабировании.
- Влияние оформления черновика на ранее выбранную фигуру.
- Обработка смены масштаба, удаления и изменения оформления во время
  активного жеста мышью.

На момент выпуска 0.2.0 третий инкремент не был реализован: отсутствовали
сохранение/чтение рисунка, группы объектов, настройки и Undo/Redo.

## [0.1.0]

### Добавлено

- Рабочий белый холст и растровое рисование мышью.
- Точка, круг и квадрат с общим абстрактным классом `Pixel`.
- Создание элементов через фабричный метод `PixelFactory`.
- Выбор инструмента, цвета и размера кисти; очистка рисунка.
- Интерполяция штрихов между событиями движения мыши.
- Проверки модели, фабрик, контроллера и JavaFX-интерфейса.
- Maven Wrapper, исключение настроек IDE и результатов сборки из Git.
- README и Git-практика с функциональными ветками, PR, самопроверкой
  и настоящим разрешением конфликта.
