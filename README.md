# GraphicEditor — кликабельный макет

Прототип интерфейса на JavaFX, аналог кликабельного макета в Figma.
Кнопки фигур переключают только состояние выбора и подпись внизу.
Кнопка очистки возвращает макет в исходное состояние.
Поля доступны для ввода, палитры — для выбора цвета, но их значения
не обрабатываются и не влияют на рабочую область.

Рабочая область — пустой визуальный элемент. Рисование, вычисление площади,
валидация параметров, модели фигур и сохранение документов не реализованы.
Дополнительные окна не предусмотрены.

Представление хранится в пакете `ui`, оформление — в
`src/main/resources/org/example/graphiceditor/css/application.css`.
CSS загружается как ресурс приложения, без абсолютных путей.
Обработчики в представлении переключают только демонстрационное состояние.

Запуск на JDK 25: `./mvnw javafx:run`.
